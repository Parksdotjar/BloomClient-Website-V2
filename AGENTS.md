# Bloom Client Website Assistant Rules

- Read `DESIGN.md` and `UI_CHANGE_HISTORY.md` before changing the website.
- Use the real Bloom flower and real Bloom Client screenshots. Never redraw the logo, generate fake launcher UI, or substitute Minecraft artwork.
- Keep wording direct. Do not add slogans, fake rankings, testimonials, statistics, lore, Minecraft jokes, or captions that restate visible content.
- Every visible button and link must have a real destination. Do not expose Sign in until Delight account OAuth works end to end.
- Keep the page OLED black with restrained Bloom blue. No hover lift, card scaling, glows, CSS particles, parallax, or decorative animation.
- Preserve open space. Do not fill unused areas with badges, icons, feature cards, or repeated brand copy.
- Run `npm test` and `npm run build` before handoff.
