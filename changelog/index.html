Version 1.1.6

LatestOctober 8, 2026
View release

New Features

  • Added Social with Bloom-account friends, encrypted direct messages, private groups of up to ten people, replies, editing, per-person reactions, screenshot sharing, pinned messages, and automatic 24-hour cleanup for unpinned history.
  • Added optional encryption verification with matching safety numbers, QR comparison, key-change detection, and a contained review flow if a friend's device identity ever changes.
  • Added friend-only instance sharing from every instance menu. Send a standalone copy or keep a pack synced with Can view and Can edit access.
  • Added real synced-pack access management so owners can review members and pending invitations, change permissions, remove access, and invalidate unused invites.
  • Added Global File Sync for safely sharing game options, server lists, voice-chat settings, resource packs, and shader packs between selected instances with backups and conflict protection.
  • Added a managed client cache for Modrinth pages, instance content and artwork, skins, capes, cloaks, and thumbnails, with capacity, location, usage, and clear controls in Settings.
  • Added a first-run Microsoft onboarding flow with a verified copyable device code, direct browser handoff, successful-account confirmation, and a Restart onboarding setting for testing.
  • Added a right-side mod detail drawer with descriptions, dependencies, compatible versions, files, and a full-width install state without losing the current list position.
  • Added automatic required-dependency installation for Modrinth mods while reusing compatible dependencies already active in the instance.
  • Added a persisted compact sidebar mode and moved AutoTune into the new Utilities hub alongside Global File Sync.

Performance Improvements

  • Replaced Social's repeated full refresh with realtime incremental delivery and an adaptive repair fallback, reducing repeated network and decryption work.
  • Made outgoing messages and reactions appear immediately in a dimmed pending state, then become fully visible only after real delivery is confirmed.
  • Expanded Modrinth browsing to 50 results per page, preloaded the next two pages and their artwork, and revealed uncached results in smooth groups of ten.
  • Kept installed instance content hydrated between views so revisiting an instance no longer rebuilds the list or briefly flashes an empty state.
  • Kept Locker wardrobes and cached cosmetic media populated during background refreshes, reducing repeated requests, rate limits, and category flicker.
  • Improved rapid Social sending with ordered encrypted queues, idempotent retries, and reconciliation protection for message bursts, reactions, and pins.

Interface & Animation Improvements

  • Replaced message hover controls with one compact right-click menu for Reply, reactions, Pin or Unpin, and sender-only Edit.
  • Improved Social loading and account switching so friends, groups, invitations, conversations, and decrypted history are ready before the page is revealed.
  • Refined the sharing wizard and direct-message invitation card with real instance artwork, direct permission labels, and compact accept or decline actions.
  • Rebuilt the instance three-dot menu as an attached action drawer with instance identity, grouped folder and sharing actions, duplication, settings, and guarded deletion.
  • Added optional recent Mod searches for the installed list and Add Mods catalog, stored locally and disabled by default.
  • Made Mods, Resource Packs, and Shaders tabs larger and allowed the selected surface to fill its complete tab segment.
  • Refined account and profile surfaces with plain white action icons, a cleaner edge-to-edge Log out footer, and a full-height profile artwork switch interaction.
  • Preserved real Modrinth project artwork throughout active and completed downloads instead of replacing it with a generic content icon.

Fixes

  • Fixed confirmed messages disappearing, stale refreshes restoring old conversations or pin state, and rapid sends arriving out of order.
  • Fixed Social appearing empty when one encrypted envelope failed and group messages failing after a device identity rotated under the same device ID.
  • Fixed reactions collapsing different people into one entry, showing an incorrect count, or adding again instead of toggling the current person's reaction off.
  • Fixed account changes briefly showing the previous account's Social data and prevented loading from ending before the new account is fully hydrated.
  • Fixed partial Social control hitboxes, pinned and member drawer spacing, sidebar gaps, unexpected drawer closing, and controls rendering beneath other layers.
  • Fixed the mod drawer remaining on Install after completion and prevented duplicate installation of compatible dependencies already present in an instance.
  • Fixed repeated Locker requests causing Minecraft rate limits, sharpened official cape rendering, and made wardrobe refresh explicitly user-controlled.
  • Fixed completed downloads losing their Modrinth artwork after navigation or a client restart.
  • Fixed Microsoft onboarding clipboard false-positives, first-click copy failures, duplicated focus borders, and uneven rounded outlines.
