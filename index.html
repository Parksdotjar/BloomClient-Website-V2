MODRINTH

Find and install content without leaving Bloom.

Search Modrinth from the selected instance. Bloom limits results to the right Minecraft version and loader, then puts every file where it belongs.

  • Mods and modpacks
  • Resource packs and shaders
  • Version and loader filtering
  • Installed content management
INSTANCES

Every setup stays in its own place.

Create a separate instance for each Minecraft version, loader, modpack, or server setup. Each one keeps its own content, Java settings, memory, resolution, and game directory.

Content
Mods, packs, and shaders per instance
Runtime
Java, memory, and launch settings
Files

GLOBAL FILE SYNC

Choose what should stay consistent.

Pick one source instance and the destinations that should receive its files. Bloom backs up existing copies before it replaces them.

  • Game options
  • Server list
  • Voice chat settings
  • Resource packs
  • Shader packs
